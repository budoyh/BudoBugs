# 数据处理

将 Cookie、Authorization header、PAT、API key、会话标识、用户数据、原始响应、源码和未披露 finding 视为敏感。仅在当前 engagement 的本地运行目录保存最小必要工件；不要把它们提交到 Git、贴入 issue、复制到公共示例或发送给未批准的模型/API。

导入 HAR 前应删除不必要域名、请求体、认证头和用户数据。导出报告前运行 finding 验证并人工审查脱敏效果。保留期、备份和销毁由任务所有者决定；BudoBugs 不提供已验证的自动清除或合规保留承诺。删除 Docker volumes、运行数据或工具目录均可能不可恢复，先确认精确范围。

当使用云模型、OOB、漏洞数据库、Caido/Burp/ZAP 或其他外部服务时，先确认服务条款、地域/保留政策和将发送的数据类别。默认不要发送原始流量、凭据或未披露漏洞细节。
