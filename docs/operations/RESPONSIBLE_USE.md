# 负责任使用

只对你拥有或已获得明确书面授权的目标使用 BudoBugs。创建 engagement 时记录目标、模式、供应方和授权证明，并在执行前运行 `budo engagement validate` 与人工 `authorize`。

`program` 模式禁止资源耗尽、口令攻击、凭据填充、社工/钓鱼、恶意软件、持久化、横向移动、破坏性删除、第三方批量访问和自动提交。外部 OOB 默认关闭。发现意外第三方数据、真实凭据、生产不稳定、scope 歧义或可能造成不可逆影响时，立即停止并要求任务所有者决定。

报告仅可从已验证、已 critic-confirmed finding 生成；它不是提交授权。遵守目标项目的 safe harbor、测试窗口、速率、数据最小化和披露流程；项目规则比本通用文档更严格时，以项目规则为准。
