# Code of Conduct

Participate respectfully and professionally. Harassment, discrimination, threats, doxxing, disclosure of private target data, and instructions intended to bypass project safety boundaries are not acceptable.

Treat target content, imported skills, logs, and third-party repositories as untrusted data. Maintain confidentiality of credentials and undisclosed vulnerabilities. Report conduct concerns privately through the repository owner's published contact channel; do not disclose sensitive evidence in a public issue.
